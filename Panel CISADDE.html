Conexión con GitHub

La clave se guarda solo en este dispositivo. Sin ella, nadie puede cambiar nada desde este panel.

Sin conectar
¿Cómo saco la clave? (una sola vez)
  1. Entra a github.com → Fine-grained token con tu cuenta.
  2. Token name: Panel CISADDE. Expiration: la que quieras (por ejemplo 1 año).
  3. Repository access: “Only select repositories” → Cisadde-Valoraciones.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Pulsa Generate token, cópialo y pégalo arriba.

6. Configuración del buzón

Los reportes y el conteo llegan a una hoja de Google tuya. Se configura una sola vez.

Sin configurar
Dirección del buzón (termina en /exec) Clave de lectura (la que pusiste en el código)
¿Cómo creo el buzón? (una sola vez, mejor desde el computador)
  1. Abre sheets.new con la cuenta de Google del centro y ponle de nombre Buzón CISADDE.
  2. Menú Extensiones → Apps Script. Borra lo que aparece escrito.
  3. Pulsa y pégalo allí.
  4. En la línea const CLAVE = 'CAMBIA-ESTA-CLAVE'; cambia el texto por una clave tuya (ej. cisadde-2026-xyz). Pulsa 💾 Guardar.
  5. Implementar → Nueva implementación → engranaje ⚙ → Aplicación web. Ejecutar como: Yo. Quién tiene acceso: Cualquier usuario. Pulsa Implementar y autoriza con tu cuenta (si dice “Google no verificó esta app”: Configuración avanzada → Ir a…).
  6. Copia la URL de la aplicación web (termina en /exec), pégala arriba junto con tu clave y pulsa Guardar y probar.

Si después cambias el código en Apps Script, usa Implementar → Gestionar implementaciones → ✏️ → Versión: Nueva para que la dirección siga siendo la misma.
