Sin conectar
¿Cómo saco la clave? (una sola vez)
  1. Entra a github.com → Fine-grained token con tu cuenta.
  2. Token name: Panel CISADDE. Expiration: la que quieras (por ejemplo 1 año).
  3. Repository access: “Only select repositories” → Cisadde-Valoraciones.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Pulsa Generate token, cópialo y pégalo arriba.
